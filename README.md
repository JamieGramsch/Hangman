# Hangman
Deutsches Hangman:
Wie man spielt:
——————————————————————

1. Wähle den Spielmodus im Terminal.

2. Bekomm ein zufälliges Wort oder lass dein Mitspieler selber schreiben.

3. Errate das Wort mit einzelnen Buchstaben mit mind. 10 Fehlern.

4. Spiel nochmal oder speichere das Wort von deinem Mitspieler.
